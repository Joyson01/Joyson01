## Featured projects

### [MARUTI · AI Desktop Assistant](https://github.com/Joyson01/AI-Desktop-Assistant)
A Linux desktop assistant that accepts voice and text commands for tasks like launching applications and adjusting volume. Built with Python and PySide6.

### [AttedDEL · Smart Attendance Management System](https://github.com/Joyson01/SAMS)
An attendance system that combines face recognition with a React dashboard. The repository includes a Python backend, camera input, and attendance reporting.

### [Greedy Round Robin Scheduler](https://github.com/Joyson01/GreedyRRScheduler)
An interactive Streamlit simulator that compares fixed and adaptive time slices in Round Robin CPU scheduling. It visualizes trade-offs in waiting time, turnaround time, and context switches.

### [3 Color Merge Puzzle](https://github.com/Joyson01/99-idea-puzzle)
A browser puzzle game with multiplayer rooms built using Express and Socket.IO.
